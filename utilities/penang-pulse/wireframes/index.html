Penang Pulse wireframes

HTML-only review surface (no PNG mocks). Interactive starring demo uses cookie penangPulseStars.

UX choice: All | Starred

  • Compact All | Starred on the title row (right-aligned) — one control, not a Konbini-style filter form; week/lede sit below on narrow widths.
  • ☆ / ★ on each card (and detail) toggles save; state persists in a local cookie.
  • Starred view filters the feed; empty state when nothing is starred.
  • Chosen over chips/toggles because two modes map cleanly and stay editorial-minimal.
