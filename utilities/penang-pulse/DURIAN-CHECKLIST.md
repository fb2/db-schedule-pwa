# Durian — try list (planning)

Informal checklist toward a future Penang Pulse series: **cultivars + farms/sellers**, not a tourism encyclopedia. Planning doc only — series not registered yet, no Guides published from this list.

Sellers are often Chinese-speaking; keep the **Chinese name** handy at the stall. Tick a type only after you’ve actually eaten it (and ideally noted where).

## Penang / Malaysia classics

Must-know clones — start here when the season is on.

- [ ] **D15** (青尼 / D15) — Penang/Kedah stall name for Chanee (Thai); frequent workhorse up north; aka Penang 15 / Juara 90; DOA registration is usually **D123** — not the same as 青皮15/D165
- [ ] **D5 Ibrahim** (易卜拉欣 / D05) — early DOA-registered clone (D5); stems often tagged **D05**; pale yellow, dessert-sweet, mild aroma; seen locally in Penang
- [ ] **D105 Ganja** (干尧 / D105) — stall “Ganja”; also 长柄 / Ganyao; long stem, floral punch, sticky-sweet; user’s source labels this **D105** (registry aliases sometimes overlap with D158 talk — confirm at stall)
- [ ] **Musang King** (猫山王 / D197) — aka Raja Kunyit / 黄姜王 / Kunyit; bitter-sweet, sticky, the stall default “king”
- [ ] **Black Thorn** (黑刺 / D200) — also Ochee; Penang / Sungai Bakap lineage; marshmallow + bitter finish
- [ ] **Red Prawn** (红虾 / D175) — Penang classic (Udang Merah); orange-red flesh; ask for *Penang* red prawn if fakes are common
- [ ] **Susu / Su Su** (牛奶) — Malay *susu* = milk; pale creamy “milk” flesh; Penang stall / kampung nickname, not one fixed clone code (D124 “Durian Susu” exists on paper elsewhere — confirm what the uncle means)
- [ ] **D24 / Sultan** (苏丹王 / D24) — workhorse creamy clone; often what gets passed off as “premium”
- [ ] **Golden Phoenix** (金凤 / D198) — also 金凤凰; milder, pale flesh; easy crowd-pleaser
- [ ] **XO** (XO) — brandy / wine-ish notes; often treated as a D24 relative, not a separate MARDI king
- [ ] **Hor Lor** (葫芦 / D163) — Penang-registered; gourd-ish shape nickname; thick creamy pulp (老树 sometimes chocolatey rumour)
- [ ] **IOI** (IOI / D168) — also Mas Muar, 金鳄鱼, 王中王; stalls often write **“D101”** or “101” — same fruit, different nickname (real MARDI D101 is another clone)
- [ ] **D13 / Hock 13** (金包 / D226) — also 福明 / Hock Beng / “Johor red prawn”; frequently confused with real 红虾
- [ ] **Tekka** (竹脚 / D160) — Hokkien *tek-ka* = bamboo leg; Buluh Bawah; marketed as Musang Queen / 猫山王后
- [ ] **604** (604 / D166) — Penang-registered number name; chase when a Balik Pulau stall lists it
- [ ] **Red Flesh (Penang)** (红肉 / D164) — Penang-registered *红肉*; don’t confuse with market “D101红肉” talk
- [ ] **Qing Pi 15** (青皮15 / D165) — Penang-registered; greener shell nickname; seasonal / farm-list find — **≠ D15 / 青尼**

## Other notable cultivars

Worth seeking if you see them — honesty over completeness. Some are marketing nicknames more than stable clones.

- [ ] **Kampung / seedling** (甘榜) — not one clone; village / ungrafted trees; note flavour + stall, not a fake “type code”
- [ ] **Raub Musang King** (劳勿猫山王) — same D197 genetics, Raub (Pahang) origin prestige; ask where the fruit came from
- [ ] **Monthong** (金枕) — Thai classic; common in mixed stalls; milder / firmer than MSW crowd
- [ ] **Creamy Bun** (奶油包 / D28) — older “butter bun” nickname; creamy, less hype-priced
- [ ] **Buaya / Crocodile** (鳄鱼 / D167) — Selangor-registered; appearance nickname; grab if labelled clearly
- [ ] **Tupai King** (松鼠王) — clone code often given as D214 in enthusiast lists; confirm at stall, don’t assume
- [ ] **Green Bamboo** (绿竹) — clone: ?; pale / grassy marketing name; only tick if the stall commits to a clear label
- [ ] **Black Pearl** (黑珍珠) — clone: ?; dark-marketing nickname; verify you’re not just buying unmarked MSW
- [ ] **D88** (D88) — Chinese: ? (sometimes sold as orange-flesh / 橙肉 talk); note what the seller actually called it
- [ ] **D13.5 / Wu Long** (乌龙) — D13 offshoot / “mistake” nickname; only if distinctly labelled vs D13
- [ ] **Real MARDI D101** (曼谷树16 / D101) — different from stall “IOI = D101”; rare to see labelled correctly — note if you ever do
- [ ] **D2** (D2) — Chinese: ?; old-school registered clone; farm curiosity more than hawker staple
- [ ] **Puyat** (Puyat) — Chinese: ?; Filipino classic; only if a Penang seller actually stocks it

## Notes

- At the stall: lead with Chinese (猫山王、黑刺、红虾…) or the D-code; English alone often fails.
- Watch label traps: **IOI ↔ “D101”**, **D13 ↔ 红虾**, **XO ↔ D24**, **D15 / 青尼 ↔ 青皮15 / D165**, **Ganja / 干尧 ↔ D105** (sometimes D158 talk), **Raub** = place not a separate clone.
- How to tick: edit this file after a real tasting; don’t invent tries.
- Series not in `_series.json` yet — this list is planning only. Register a slug / Guides only when you’re ready to publish.
- Seasonality matters; empty stalls in off-months are normal, not a failure of the checklist.
